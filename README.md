# VanishCam

VanishCam is a Python webcam effects project that processes video locally. It
lets you disappear from the camera feed with gesture-controlled effects.

## What I built

- **Normal Vanish:** recognizes a V-hand gesture and creates a dissolve effect.
- **Naruto Vanish:** recognizes joined hands and adds animated smoke, a falling
  wooden log, and a sound effect.
- Live webcam preview and optional virtual-camera output.
- Background capture and person segmentation for the disappearance effects.
